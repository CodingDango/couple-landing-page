# Modern Couples Relationship Timeline

A modern, responsive single-page application built to showcase a relationship journey. This project demonstrates advanced UI/UX implementation, 3D model integration, and smooth interactive animations.

**[Live Demo Link](https::\\couple-landing-page.vercel.app)**

## Features

- **Scroll-Driven Storytelling:** Sections fade in naturally as you scroll through your timeline.
- **Interactive 3D Heart:** A Three.js-powered model you can spin and explore with your mouse.
- **Full-Width Galleries:** Responsive image carousels that showcase photos without cropping.
- **Animated Statistics:** Relationship milestones with smooth count-up animations.
- **Mobile-First Design:** Flawless experience across all devices and screen sizes.

## Tech Stack

- **Framework**: React (Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Shadcn/UI
- **3D Engine**: Three.js
- **Animations**: Framer Motion
- **Carousels**: Swiper.js
- **Counters**: React CountUp
